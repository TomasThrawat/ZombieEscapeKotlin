# Zombie Escape Kotlin

Native Android game written in Kotlin using a custom Canvas View.

## Gameplay

- Collect 3 energy beacons.
- Avoid the zombie horde.
- Reach the green exit after collecting every beacon.
- Left-side virtual joystick controls movement.
- Hold SPRINT to move faster.
- Pause, restart, and return to the menu.

## Build

GitHub Actions runs unit tests, Android lint with warnings treated as errors, then builds the debug APK and uploads it as an artifact.

## Constraints

- Kotlin + Android SDK only.
- No HTML.
- No JavaScript.
- No WebView.
- No external game engine.
- No network permission.
- No runtime permissions.
- No external game assets required.
